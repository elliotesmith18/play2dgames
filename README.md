# Play 2D Games

Home page for play2dgames.com: a small arcade of daily browser games.

- `index.html`: the game lobby
- `privacy.html`: privacy policy for every game on the domain
- `consent.js`: shared cookie banner; one choice covers all game subdomains (also copied into each game repo)
- `fonts.css`, `fonts/`: self-hosted pixel fonts (SIL Open Font License)

Games live in their own repos on subdomains, e.g. Relic at relic.play2dgames.com.
